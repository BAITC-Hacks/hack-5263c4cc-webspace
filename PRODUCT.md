# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Freedom Finance hackathon reviewers and analysts investigating the supplied account-transfer graph. The task is to inspect observed evidence, compare role hypotheses and export the required submission files.

## Product Purpose

Aqsha Lens (Money Graph engine) provides deterministic role hypotheses, community analysis and an investigation queue, with optional bounded AI explanations. Success means covering the published Finance case requirements and making every conclusion inspectable.

## Operating Context

This is a local React/Vite and FastAPI application. Synthetic data supports a credential-free demonstration. The organizer dataset is loaded locally and is not redistributed. The event deadline is 18:00 Asia/Almaty on 23 September 2026.

## Capabilities and Constraints

- Preserve every input account, including isolated seeds, and the exact three CSV contracts.
- A depth-four node is an observation boundary, not an established final beneficiary.
- Scores indicate heuristic review priority and rule fit, never probability of crime.
- All eight optional case categories are implemented as bounded analytical features.
- AI reads application-scoped evidence only and cannot write scores, exports or arbitrary tools.
- Graph analysis works offline without an API key or subscription.

## Brand Commitments

The user requires a complete Base UI/shadcn dashboard with Phosphor icons and assistant-ui for the copilot. Square UI Dashboard 4 supplies the composition reference. After rejecting earlier green, monochrome and navy/cobalt versions, the user delegated the final direction choice. The selected world uses warm white, graphite, a quiet light sidebar and restrained copper emphasis, informed by inspected Mercury and Linear interfaces. Use compact factual cards, a visible review queue, readable circular account glyphs and focused transfer neighborhoods. Sidebar and evidence panels collapse. The product name is Aqsha Lens, with a generated text-free mark. Bright multicolor surfaces, decorative icon tiles, oversized rainbow charts and invented trend indicators are anti-references.

## Evidence on Hand

The published Finance brief, local organizer Parquet files, a clearly labeled original synthetic fixture, exact exports, deterministic tests and dated source-linked ecosystem research. No labeled ground truth or measured financial detection accuracy is available.

## Product Principles

1. Separate observed facts, hypotheses and missing evidence.
2. Prefer readable standard controls and direct access to investigative tasks.
3. Preserve provenance and keep secrets and organizer records out of Git and logs.
4. Reuse maintained components while retaining a small deterministic core.
